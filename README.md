# Easy 3D — tdasolutions

![Easy 3D](brand/easy3d-logo.png)

Phần mềm thiết kế và sản xuất 3D của **tdasolutions**.
Website: https://tdasolutions.com.vn/.

Kho này chỉ chứa bộ cài, logo, chữ ký cập nhật và thông tin phiên bản. Mã nguồn được quản lý riêng trong repository private.

Ứng dụng kiểm tra cập nhật trong Cài đặt. Khách chỉ cần nhập token do tdasolutions cấp để kết nối service.

Tải bản mới nhất tại các đường dẫn cố định:

[**Tải Easy 3D cho Windows**](https://phantom0708.github.io/tda-3d-releases/releases/latest/easy3D-setup.exe)

[**Tải Easy 3D cho macOS**](https://phantom0708.github.io/tda-3d-releases/releases/latest/easy3D-mac.dmg)

Bản Mac Universal hỗ trợ Apple Silicon và Intel, yêu cầu macOS 14 trở lên.
Các đường tải tự động cập nhật sau mỗi lần phát hành public.
